# AI Gateway API Center access contract (500)

This example composes the AI Gateway routing layer with an APIM product access
contract and registers the resulting API hierarchy in Azure API Center.

It creates no application or Logic Apps workflow. The subscription keys are
generated by the APIM provider at apply time; this example neither supplies nor
prints them.

## Prerequisites

- Terraform 1.8 or later
- Azure credentials with rights to create Microsoft.ApiCenter and APIM resources
- Microsoft.ApiCenter provider registration

## Contract

- Stable API Center ARM version: `2024-03-01`
- Catalog hierarchy: service, `default` workspace, environment, API, version,
  OpenAPI definition, and APIM deployment
- APIM access: published product, product/API association, approval-gated
  subscription created in `submitted` state, and a named fragment applying rate
  and quota limits
- Product policies wait for both the product and referenced fragment; the API
  policy waits for its backend pool and uses one `forward-request` backend
  element so the XML remains valid
- API Center deployment environment and definition values are emitted as
  service-relative references

## Validate

From the repository root:

```bash
terraform -chdir=examples init -backend=false
terraform -chdir=examples validate
terraform -chdir=examples test -test-directory=tests/unit/integration/api_center
python3 examples/tests/schema/api_center_schema_test.py
terraform -chdir=examples/tests/schema/api_center_arm init -backend=false
terraform -chdir=examples/tests/schema/api_center_arm plan -refresh=false -lock=false
```

The workflow mock uses the configuration path only and does not deploy Azure
resources. The no-refresh schema plan exercises AzAPI 2.13's embedded ARM
validator for every writable body without applying anything. Apply the example
only after replacing `.invalid` placeholders and confirming the required APIM
SKU and API Center quota.

## Cleanup

Use your normal landing-zone destroy procedure. The API Center service, catalog
children, and APIM access contract are removed by Terraform.
